# 隐私政策 / Privacy Policy

**生效日期：** 2026-11-08  
**适用项目：** Aria2Desktop（<https://github.com/Young-ZJ66/Aria2Desktop>）

## 概述

Aria2Desktop 是一个本地下载管理工具。我们**不收集、不上传、不出售**任何遥测、分析或个人数据。应用不需要账户，也没有项目自建的统计服务器。

## 本地存储的数据

以下数据只保存在你的电脑上，位于应用的 userData 目录（例如 Windows 的 `%APPDATA%\aria2-desktop`）：

- 应用设置、连接配置、任务模板、完成规则和插件配置；
- 下载历史、任务来源信息和统计信息；
- 主进程日志（`logs/main.log`，用于排查问题，可随时删除）；
- 已安装的插件及其数据。

你可以在设置中清理历史，或手动删除上述目录来移除所有本地数据。

## 网络连接

应用只会在以下情况发起网络连接：

1. **下载任务**：连接你添加的 HTTP/FTP/BitTorrent/Metalink 链接、Tracker 和 DHT 网络。目标站点会像普通下载一样看到你的 IP 地址和请求头。
2. **检查更新**：向 GitHub Releases 查询最新版本；不会发送设备标识或使用统计。
3. **插件市场（可选）**：启用后从配置的 GitHub 仓库地址获取插件索引和插件包。
4. **Web 控制台（默认关闭）**：启用后在本机端口监听；你配置的 Token 和 IP 白名单只保存在本地。若你允许局域网访问，连接的设备可以看到任务信息。
5. **用户主动配置的 Webhook / 通知**：完成规则中的 Webhook 会把任务名称、状态等发送到你指定的地址。

这些请求遵循对应第三方服务的隐私政策。项目不运营代理服务器，也不记录你的下载内容。

## 浏览器扩展

浏览器扩展只在你点击扩展按钮时，把当前标签页的下载链接发送到本机 `127.0.0.1` 上的应用接口；不会上传浏览历史。扩展的配对密钥保存在本地。

## 第三方组件

应用内置或按需下载 aria2、yt-dlp、ffmpeg 等第三方程序。它们由各自项目维护，遵循各自的许可证和隐私政策。应用不会把它们的运行数据发送给项目维护者。

## 儿童隐私

本应用不面向儿童，也不收集任何人的个人信息。

## 政策变更

如果本政策发生重大变化，我们会在仓库中更新本文件并修改生效日期。继续使用新版本即表示你了解更新后的政策。
