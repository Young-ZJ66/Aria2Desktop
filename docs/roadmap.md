# Aria2 Desktop 路线图

> 更新于 2026-11-09，适用于 v1.3.x 系列。版本范围会随社区反馈调整，已发布内容以 [GitHub Releases](https://github.com/Young-ZJ66/Aria2Desktop/releases) 为准。

v1.3.3 已发布，包含 21 种语言、流媒体任务删除文件与内置 Auto Retry 示例插件，并完成设置页与全局界面一致性优化。当前开发线为 **v1.3.4 分发与稳定性**。

## 持续改进（不绑定版本）

- **性能**：批量 RPC（`system.multicall`）覆盖更多轮询路径；任务列表虚拟滚动；统计页增量绘制；SQLite 历史分页与归档策略。
- **安全**：IPC 参数 schema 全覆盖；路径白名单持续审计；插件权限最小化与签名吊销列表；依赖供应链扫描。
- **可靠性**：下载引擎异常自动恢复；网络切换与代理变化自适应；日志脱敏与诊断包一键导出。
- **文档**：插件开发指南、API 参考、常见故障排查、发版检查清单随版本同步更新。

## 优先级

1. v1.3.4 分发与稳定性（当前）
2. v1.3.5 内容订阅与媒体工作流
3. v1.3.6 远程与自动化
4. v1.3.7 插件生态与可访问性

## 非目标

以下方向暂不纳入路线图：内置 BT 资源搜索、网盘直链下载、原生移动 App、ED2K 支持、Docker 版 headless、迁移到 Tauri。若社区需求强烈，会另行评估。
